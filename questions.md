# Вопросы для самопроверки

**1. Что такое основание системы счисления?**  
Ответ: Количество различных цифр (символов), используемых для записи чисел в данной системе. Например, в двоичной системе основание равно 2.

**2. Как перевести число из десятичной системы в двоичную?**  
Ответ: Последовательно делить число на 2, записывая остатки, пока не получится 0. Затем прочитать остатки в обратном порядке (снизу вверх).

**3. Сколько двоичных разрядов соответствует одной шестнадцатеричной цифре?**  
Ответ: Четыре. Поэтому hex удобно использовать для компактной записи двоичных данных.
