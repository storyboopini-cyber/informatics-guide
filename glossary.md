# Глоссарий: системы счисления

**Система счисления** — способ записи чисел с помощью символов (цифр). Определяется основанием (базой) — количеством различных цифр, используемых для записи.

**Двоичная система (binary)** — система с основанием 2. Используются только цифры 0 и 1. Лежит в основе работы компьютеров, так как соответствует двум состояниям сигнала (есть ток / нет тока).

**Восьмеричная система (octal)** — система с основанием 8. Цифры от 0 до 7. Удобна для компактной записи двоичных чисел: одна восьмеричная цифра соответствует трём двоичным разрядам.

**Шестнадцатеричная система (hexadecimal)** — система с основанием 16. Цифры 0–9 и буквы A–F (где A=10, B=11, ..., F=15). Одна hex-цифра соответствует четырём двоичным разрядам, поэтому широко применяется в программировании и адресах памяти.

**Основание системы счисления** — количество различных символов (цифр), используемых для записи чисел в данной системе. Например, в десятичной — 10, в двоичной — 2.

**Разряд** — позиция цифры в записи числа. Значение цифры зависит от её позиции (разряда) и основания системы. Младший разряд — крайний правый.

**Перевод числа** — преобразование записи числа из одной системы счисления в другую. Основные способы: деление на основание с остатками (из десятичной) и разложение по степеням (в десятичную).

**Бит** — минимальная единица информации в двоичной системе. Один бит может принимать значение 0 или 1. Восемь бит образуют байт.
